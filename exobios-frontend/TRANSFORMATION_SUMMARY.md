## 🎯 HOW TO USE

### 1. Link the Design System

```html
<link rel="stylesheet" href="design-system.css" />
```

### 2. Use Pre-Built Components

```html
<button class="btn btn-primary">Click me</button>
<div class="card">Content</div>
<div class="badge badge-stable">Stable</div>
```

### 3. Apply Responsive Classes

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
  <!-- Items -->
</div>
```

### 4. Customize with CSS Variables

Edit `:root` in design-system.css to change colors globally:

```css
:root {
  --primary-500: #22c55e; /* Change to your color */
  --accent-500: #06b6d4; /* Change to your color */
}
```

## 📞 SUPPORT & TROUBLESHOOTING

### Issue: Colors not showing

**Solution:** Make sure `design-system.css` is linked in `<head>`

### Issue: Layout broken on mobile

**Solution:** Check responsive classes are applied (grid-cols-1, md:grid-cols-2)

### Issue: Fonts look weird

**Solution:** Verify Google Fonts link is present

### Issue: Animations choppy

**Solution:** Check browser DevTools - disable hardware acceleration if needed

### Issue: Custom colors not working

**Solution:** Update CSS variables in `:root` section

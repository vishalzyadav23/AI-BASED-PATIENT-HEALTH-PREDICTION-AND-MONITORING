## 💻 HOW TO USE

### Using Components in HTML

```html
<!-- 1. Link the design system (copy this to all HTML pages) -->
<link rel="stylesheet" href="design-system.css" />

<!-- 2. Use buttons -->
<button class="btn btn-primary">Click me</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-danger">Delete</button>

<!-- 3. Use cards -->
<div class="card">
  <h3>Card Title</h3>
  <p>Card content here</p>
</div>

<!-- 4. Use badges for status -->
<div class="badge badge-stable">✓ Stable</div>
<div class="badge badge-alert">⚠ Monitor</div>
<div class="badge badge-critical">🚨 Critical</div>

<!-- 5. Use responsive grid -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-lg">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
```

### Customizing Colors

Edit the CSS variables in **design-system.css**:

```css
:root {
  --primary-500: #22c55e; /* Change primary color */
  --accent-500: #06b6d4; /* Change accent color */
  --danger-500: #ef4444; /* Change danger color */

  /* All other colors will adapt automatically */
}
```
